# Game Store Project

## Overview
This project is a web-based game store that showcases various games, including board games. The site allows users to view game details and add them to their cart.

## Files
- **index.html**: The main HTML page displaying various games with descriptions and "Add to Cart" buttons.
- **board-games.html**: A dedicated page for board games, featuring similar sections as index.html but focused solely on board games.
- **css/styles.css**: The stylesheet for the project, defining the layout, colors, fonts, and other visual aspects of the HTML pages.
- **README.md**: Documentation for the project, including setup instructions and features.

## Features
- User-friendly interface for browsing games.
- Detailed descriptions for each game.
- "Add to Cart" functionality for easy shopping.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the `index.html` or `board-games.html` file in a web browser to view the project.
3. Ensure that the `css/styles.css` file is linked correctly for proper styling.
