# Game Store Project

## Overview
This project is a simple game store web application that allows users to browse and purchase various games and decks. It consists of a main page showcasing the available games and a dedicated purchase page for handling transactions.

## Project Structure
```
game-store-project
├── src
│   ├── index.html         # Main HTML file for the game store
│   ├── purchase.html      # Second purchase page for selecting games and decks
│   ├── css
│   │   ├── styles.css     # Styles for the project
│   └── js
│       ├── main.js        # JavaScript for the main page functionality
│       └── purchase.js     # JavaScript for the purchase page functionality
```

## Features
- **Game Browsing**: Users can view a variety of games and decks on the main page.
- **Purchase Interface**: A dedicated purchase page allows users to select games and decks for purchase.
- **Responsive Design**: The application is designed to be responsive and user-friendly across devices.
- **JavaScript Functionality**: Interactive elements are managed through JavaScript, enhancing user experience.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the `index.html` file in your web browser to view the main page.
3. Navigate to the `purchase.html` file to access the purchase interface.
